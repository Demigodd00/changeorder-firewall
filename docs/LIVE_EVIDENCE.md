## Boundaries and remaining gates

The recorded amendment path establishes this contract's behavior for one live positive/negative scenario. It does not prove arbitrary model consistency, true delivery, identity of a real supplier, or production safety. The public site's finalized read-only inspector and buyer MetaMask deploy/fund/approve path were checked in a real browser, with a human confirming each wallet prompt. Supplier-side browser signing remains untested; the supplier actions in the second case used a test-only script wallet. Mobile pairing lacks a Reown project ID. Keep technical behavior, distinctiveness versus MatchPay, and review evidence as separate claims rather than treating a live transaction as a guaranteed Portal score.
